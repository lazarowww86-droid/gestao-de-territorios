ATUALIZAÇÃO V26 — MAPA GERAL AUTOMÁTICO PARA TODAS AS CONGREGAÇÕES

NÃO PUBLICAR DURANTE A CERTIFICAÇÃO DA MICROSOFT
- Guarde este pacote até a certificação atual terminar.
- Esta preparação não altera o GitHub nem o aplicativo que está sendo avaliado.

O QUE MUDA
- O administrador cola o link compartilhado do Google Maps ao adicionar ou editar um território.
- O aplicativo reconhece automaticamente a latitude e a longitude do link.
- O ponto aparece no Mapa geral da congregação correta.
- Cada congregação continua vendo somente os próprios territórios.
- O marcador mantém as cores de território finalizado, parcial e em andamento.
- Os territórios antigos são migrados automaticamente quando um administrador entra no aplicativo.

ARQUIVOS NECESSÁRIOS
- O ZIP do site contém os arquivos completos para o GitHub Pages.
- O arquivo cloudflare-worker-v26.js atualiza o Worker já usado pelas notificações.
- As regras do Firestore foram preservadas e não precisam ser publicadas novamente nesta atualização.

ORDEM CORRETA PARA PUBLICAR DEPOIS DA CERTIFICAÇÃO
1. No Cloudflare, abra o Worker gestao-territorios-notificacoes.
2. Edite o código e substitua tudo pelo conteúdo de cloudflare-worker-v26.js.
3. Publique o Worker. As variáveis ONESIGNAL_APP_API_KEY e ONESIGNAL_APP_ID permanecem as mesmas.
4. Somente depois envie ao GitHub os arquivos do ZIP do site, mantendo as pastas icons e push.
5. Aguarde o GitHub Pages atualizar.
6. Feche completamente o aplicativo instalado e abra novamente para receber o cache V26.

TESTE RECOMENDADO
1. Entre como administrador.
2. Adicione um território e cole um link compartilhado do Google Maps.
3. Salve o território.
4. Abra Mapa geral e confira se o ponto apareceu.
5. Toque no ponto e confirme se o link original abre no Google Maps.

IMPORTANTE
- Não é necessário informar latitude ou longitude manualmente.
- Links curtos maps.app.goo.gl são resolvidos pelo Cloudflare Worker.
- Links completos que já contêm coordenadas são reconhecidos diretamente pelo aplicativo.
- Um link que não possa ser localizado não será salvo silenciosamente: o aplicativo pedirá um novo link.
- As notificações OneSignal, curtidas, usuários, programações, regras e separação por congregação foram preservadas.
